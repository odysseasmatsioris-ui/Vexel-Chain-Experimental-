# Vexel Chain — Technical Specification

## Overview
Vexel Chain is an experimental blockchain project created for learning, research, and open development.  
The project explores how blockchains, mining, and consensus mechanisms work in practice.

Vexel Chain is not an investment and makes no guarantees of value.

---

## Coin Information
Name: Vexel  
Symbol: VXL  
Type: Native blockchain coin  
Stage: Experimental  

VXL is the native coin of the Vexel Chain network and is used for transaction fees and mining rewards.

---

## Purpose
The purpose of Vexel Chain is to:
- Learn how blockchain technology works
- Experiment with mining and consensus
- Build transparently in public
- Educate through open-source development

The project is not intended as a financial product.

---

## Consensus Mechanism
Consensus Type: Proof of Work (PoW)

Blocks are produced through mining, where participants perform computational work to secure the network.

Mining is open and permissionless for experimental purposes.

---

## Mining Algorithm
Algorithm: SHA-256 (educational use)

This algorithm is chosen for simplicity and learning, not for competition with existing networks.

---

## Block Parameters
Target Block Time: ~30 seconds  
Difficulty Adjustment: Every 10 blocks  
Initial Difficulty: Low (to allow easy participation)

---

## Supply Model
Supply Type: Inflationary  
Block Reward: 50 VXL per block  

There is no fixed maximum supply. New coins are created as mining rewards to incentivize participation and secure the network.

---

## Transaction Fees
Transaction fees are intentionally kept low.

Purpose of fees:
- Prevent network spam
- Incentivize miners
- Maintain network stability

Fees are paid in VXL.

---

## Governance & Control
Vexel Chain is currently maintained by its creator during the experimental phase.

All rules and parameters are transparent and documented publicly.

Future governance models may be explored as part of the learning process.

---

## Transparency & Ethics
- No token sales
- No guaranteed returns
- No promises of profit
- No hidden mechanics

All development is done openly and documented publicly.

---

## Disclaimer
Vexel Chain is an experimental project provided for educational purposes only.

Participation is voluntary and at your own risk.  
VXL is not intended to represent an investment or store of value.
