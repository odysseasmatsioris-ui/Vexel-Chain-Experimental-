# Vexel Miner (Simulation)

Vexel Miner is an **educational mining simulator** created for learning how
blockchain mining software behaves.

## Features
- Realistic mining terminal output
- Automatic share acceptance
- Persistent balance per user
- Runs on Android using Pydroid 3

## Disclaimer
This project is a **simulation only**.
- No real cryptocurrency
- No real blockchain
- No financial value
- Educational use only

## Requirements
- Android phone
- Pydroid 3

## Run
```bash
python vexel_miner.py
