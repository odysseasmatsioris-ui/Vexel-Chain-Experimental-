# Vexel Chain

Vexel Chain is an experimental blockchain project built for learning, research, and open development.

## Purpose
- Learn how blockchains work
- Understand mining and consensus
- Build transparently in public

## Status
Early experimental stage. No live network.

## Disclaimer
This project is not an investment.
No tokens are for sale.
No guarantees are made.

## Philosophy
Build slowly. Learn openly. Stay honest.
